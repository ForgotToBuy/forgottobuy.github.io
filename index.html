About me

I build what keeps communities online.

I build backend systems, desktop tools and the control panels that go on top of them. Most of it is for online communities: a virtual trucking company, a radio station, game servers. The kind of thing somebody notices within minutes if it breaks.

Right now I'm building NorthLaneMP, a multiplayer server for Euro Truck Simulator 2. Before that came the Nordan Transport hub and its telemetry overlay, a self-hosted AI workstation, the core plugin for the GlobalSMP Minecraft network, and the staff panel for SimNation Radio. Those last three have since shut down, but the work is still here.

Every project here was built for a group I was already part of, so when something breaks I hear about it from the person it broke for. I check my own code for the things that actually get exploited, and everything ships through a proper deploy path.

  • Game servers
  • Online communities
  • Desktop tools
  • Security

Nordan VTC Telemetry

A heads-up display that reads live physics data out of the game's shared-memory file and draws it over the window. It shows up when you start driving and goes away when you pause, so there's nothing to manage while you're moving.

MidNightAI

A chat workstation I ran on my own infrastructure, wired to Groq's LPU inference so responses came back fast. Two-factor on accounts, conversation history in MySQL, and answers rendered as real Markdown rather than a wall of asterisks. It's no longer running.

  • Laravel 11
  • Vue 3
  • Groq API
  • MySQL

GlobalSMP

A multi-server Minecraft network that ran behind a Velocity proxy. I was lead developer on the core plugin: the Paper-side layer every server loaded, so a player's data stayed consistent in MySQL when they moved between servers. The network has since shut down.

  • Java
  • Paper API
  • Velocity
  • MySQL
